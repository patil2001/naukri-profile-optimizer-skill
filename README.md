# naukri-profile-optimizer (Claude Code skill)

Claude Code skill that audits and optimizes a Naukri.com profile so recruiter (Resdex) searches surface it.

- Mines live Naukri job listings for the most-demanded skill tags
- Gap analysis: adds only keywords backed by your resume
- Rules for headline, key skills, IT skills table, employment, profile summary, projects, career profile, certifications
- Drafts all edits for approval before changing the profile

## Install

```bash
git clone https://github.com/patil2001/naukri-profile-optimizer-skill
cp -r naukri-profile-optimizer-skill/naukri-profile-optimizer ~/.claude/skills/
```

Then ask Claude Code: "optimize my naukri profile".

Pairs well with resume-ats-optimizer, job-description-analyzer, resume-tailor and resume-bullet-writer skills.
